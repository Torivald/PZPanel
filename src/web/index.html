Автосортировка модов

        
Результат сначала показывается как предпросмотр — порядок меняется только после «Применить», а в сервер попадёт после «Сохранить». Меняйте порядок только при остановленном сервере и до начала игры: в уже начатом мире смена порядка модов может испортить сохранение.

    ZombieBuddy — одобрения Java-модов
    
        
    
        
    Общий файл для игры и сервера на этом ПК. После обновления мода его хэш меняется, и ZombieBuddy спросит снова.
