# История изменений PZ Panel

Полные описания выпусков — на странице [Releases](https://github.com/Torivald/PZPanel/releases).

## 1.2

- **📌 Закрепить мод** — фиксирует версию мода из Мастерской: панель копирует его в `Zomboid/mods`, записывает `_frozen_manifest.txt`, убирает ID из `WorkshopItems=`, и обновление в Мастерской больше не ломает сервер. Для Java-модов можно сразу одобрить jar в ZombieBuddy (по sha256). *(@xenking)*
- **Закрепление на Windows без настройки** — источник берётся из папок Мастерской сервера и клиента Steam, а если мода там нет, панель сама скачивает SteamCMD и мод (параметры `steamcmd`, `steamcmdCache`). Пока сервер запущен, закрепление блокируется.
- **Режим `serverMode=remote`** — панель в одном контейнере, сервер в другом: RCON по `rconHost`, нагрузка из файла `.panel-metrics.json`, который пишет `dist/linux/pz-metrics.sh`. *(@xenking)*
- Исходники, сборка и упаковка (`scripts/package.sh`) лежат в репозитории; в README и инструкции добавлены скриншоты.

**Добавлено в 1.2:** «📌 Закрепить» (Linux и Windows), одобрение Java-модов в ZombieBuddy при закреплении, `serverMode=remote` + `rconHost`, `pz-metrics.sh`, параметры `steamcmd`/`steamcmdCache`, скриншоты и раздел «Панель в отдельном контейнере» в документации.
**Изменено:** версия 1.2; инструкция и README дополнены; на Windows при закреплении перезаписывается `_frozen_workshop_items.txt`, снимается атрибут «только чтение» перед удалением старой копии.

## 1.1

- **Вкладка «Миры»**: список миров (имён сервера) с отдельными настройками, модами и песочницей; создать новый мир (только настройки / полная копия / по умолчанию); сделать активным; сбросить (вайп — с аккаунтами или без); переименовать; удалить; «Сохранения без настроек» — старые папки можно вернуть в строй.
- **Автоматический бэкап перед опасными действиями** (сброс, удаление, переименование) — можно отключить галочкой.
- **Бэкапы**: колонка «Мир» и кнопка **«Восстановить»** (перед восстановлением делается копия `_beforerestore`).
- При смене активного мира панель переписывает `-servername` в стартовом скрипте (старый скрипт — в `PZPanel/file_backups`).

**Добавлено:** вкладка «Миры» (Worlds.java), автобэкапы, восстановление из бэкапа, колонка «Мир» в списке бэкапов.
**Исправлено:** бэкап мира `Torivald` захватывал и конфиги похожих миров (`Torivald_old`, `Torivald2`) — теперь только свои файлы.
**Изменено:** переключение мира меняет `-servername` в запуске и подхватывает его настройки/моды.

## 1.0

- **Обзор и консоль** — запуск, перезапуск с предупреждением игроков, остановка с сохранением, «Убить», живая консоль, ответы на вопросы ZombieBuddy (y/n), ежедневный перезапуск, авто-перезапуск при падении.
- **Нагрузка сервера** — ЦПУ и ОЗУ процесса с графиками за 30 минут, лимит Java (-Xmx), пик памяти, загрузка машины.
- **Карта** — карта мира с игроками, здания по категориям (аптеки, оружейные, полиция…), улицы, города, зоны, плотность зомби, поиск, телепорт, ссылка на место; подложка «вид сверху» по этажам через pzmap2dzi (`render_top_view`).
![Карта](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/map.png)
- **Игроки** — роли, баны, последний вход, позиции.
- **Моды** — порядок загрузки перетаскиванием, добавление из Мастерской (ссылка, коллекция, поиск), проверка зависимостей, локальные и замороженные моды.
- **Настройки сервера (ini), песочница, файлы, ZombieBuddy, бэкапы.**
- **Безопасность** — вход по паролю `panelPassword`, токен против CSRF, проверка Host.
- **Linux** — служба systemd (`pzpanel.service`), установка `install_panel.sh`.
