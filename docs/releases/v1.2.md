Веб-панель выделенного сервера Project Zomboid (Build 42) — моды, миры, карта, игроки, бэкапы в одном окне браузера.

![Моды: кнопка «Закрепить»](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/mods_pin.png)

## Скачать

| Система | Архив |
|---|---|
| **Windows** | `PZPanel_1.2_Windows.zip` (ниже, в «Assets») |
| **Linux** | `PZPanel_1.2_Linux.zip` (ниже, в «Assets») |

**Windows:** распакуйте папку `PZPanel` внутрь «Project Zomboid Dedicated Server», запустите `PZPanel.bat` → откроется http://127.0.0.1:8766/.
**Linux:** из распакованной папки выполните `bash install_panel.sh`, а для службы systemd — `sudo bash install_panel.sh --service`.
Панели не нужно ничего ставить: Java и библиотеки берутся из самого сервера. Подробности — [docs/PANEL.md](https://github.com/Torivald/PZPanel/blob/main/docs/PANEL.md).

## Что нового в 1.2

- **📌 Закрепить мод** — фиксирует версию мода из Мастерской: панель копирует его в `Zomboid/mods`, записывает `_frozen_manifest.txt`, убирает ID из `WorkshopItems=`, и обновление в Мастерской больше не ломает сервер. Для Java-модов можно сразу одобрить jar в ZombieBuddy (по sha256). *(@xenking)*
- **Закрепление на Windows без настройки** — источник берётся из папок Мастерской сервера и клиента Steam, а если мода там нет, панель сама скачивает SteamCMD и мод (параметры `steamcmd`, `steamcmdCache`). Пока сервер запущен, закрепление блокируется.
- **Режим `serverMode=remote`** — панель в одном контейнере, сервер в другом: RCON по `rconHost`, нагрузка из файла `.panel-metrics.json`, который пишет `dist/linux/pz-metrics.sh`. *(@xenking)*
- Исходники, сборка и упаковка (`scripts/package.sh`) лежат в репозитории; в README и инструкции добавлены скриншоты.

## Полный список изменений 1.0 → 1.2

**Добавлено в 1.2:** «📌 Закрепить» (Linux и Windows), одобрение Java-модов в ZombieBuddy при закреплении, `serverMode=remote` + `rconHost`, `pz-metrics.sh`, параметры `steamcmd`/`steamcmdCache`, скриншоты и раздел «Панель в отдельном контейнере» в документации.
**Изменено:** версия 1.2; инструкция и README дополнены; на Windows при закреплении перезаписывается `_frozen_workshop_items.txt`, снимается атрибут «только чтение» перед удалением старой копии.
