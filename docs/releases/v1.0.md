Веб-панель выделенного сервера Project Zomboid (Build 42) для Windows и Linux.

![Обзор и консоль](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/overview.png)

## Скачать

| Система | Архив |
|---|---|
| **Windows** | `PZPanel_1.0_Windows.zip` (ниже, в «Assets») |
| **Linux** | `PZPanel_1.0_Linux.zip` (ниже, в «Assets») |

**Windows:** распакуйте папку `PZPanel` внутрь «Project Zomboid Dedicated Server», запустите `PZPanel.bat` → откроется http://127.0.0.1:8766/.
**Linux:** из распакованной папки выполните `bash install_panel.sh`, а для службы systemd — `sudo bash install_panel.sh --service`.
Панели не нужно ничего ставить: Java и библиотеки берутся из самого сервера. Подробности — [docs/PANEL.md](https://github.com/Torivald/PZPanel/blob/main/docs/PANEL.md).

## Возможности 1.0

- **Обзор и консоль** — запуск, перезапуск с предупреждением игроков, остановка с сохранением, «Убить», живая консоль, ответы на вопросы ZombieBuddy (y/n), ежедневный перезапуск, авто-перезапуск при падении.
- **Нагрузка сервера** — ЦПУ и ОЗУ процесса с графиками за 30 минут, лимит Java (-Xmx), пик памяти, загрузка машины.
- **Карта** — карта мира с игроками, здания по категориям (аптеки, оружейные, полиция…), улицы, города, зоны, плотность зомби, поиск, телепорт, ссылка на место; подложка «вид сверху» по этажам через pzmap2dzi (`render_top_view`).
![Карта](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/map.png)
- **Игроки** — роли, баны, последний вход, позиции.
- **Моды** — порядок загрузки перетаскиванием, добавление из Мастерской (ссылка, коллекция, поиск), проверка зависимостей, локальные и замороженные моды.
- **Настройки сервера (ini), песочница, файлы, ZombieBuddy, бэкапы.**
- **Безопасность** — вход по паролю `panelPassword`, токен против CSRF, проверка Host.
- **Linux** — служба systemd (`pzpanel.service`), установка `install_panel.sh`.
