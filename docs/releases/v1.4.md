## Что нового в 1.4

- **Версия и «Что нового».** В боковом меню — версия панели и кнопка «Что нового»: окно со списком изменений на языке интерфейса (после обновления открывается один раз само).
- **Проверка обновлений.** Кнопка «Проверить обновление» смотрит последний релиз на GitHub и, если вышла новая версия, показывает описание и предлагает **установить**: скачивается архив для вашей системы, подменяется `pzpanel.jar` (прежний сохраняется как `pzpanel.jar.bak`), остаётся перезапустить панель. На Windows новый файл применяется при следующем запуске `PZPanel.bat`.

  ![Проверка обновления](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/update.png)
- **`pz-metrics.sh` для панели в отдельном контейнере.** Внутри контейнера показывает потребление **всего контейнера** (ЦПУ, ОЗУ как в `docker stats`, процессы и потоки по cgroup); процесс сервера ищется по `/proc` (`ProjectZomboid64` или `java … zombie.network.GameServer`, не нужны `pgrep`/`ps`), диагностика пишется в stderr, свой шаблон — `PZ_MATCH`.
- Мелкие исправления английского перевода интерфейса.

# 🇬🇧 English

A web panel for a Project Zomboid (Build 42) dedicated server — mods, worlds, map, players, backups in one browser window.

![What's new](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/whatsnew_en.png)

## Download

| System | Archive |
|---|---|
| **Windows** | `PZPanel_1.4_Windows.zip` (in "Assets" below) |
| **Linux** | `PZPanel_1.4_Linux.zip` (in "Assets" below) |

**Windows:** unpack the `PZPanel` folder into "Project Zomboid Dedicated Server" and run `PZPanel.bat` → http://127.0.0.1:8766/ opens.
**Linux:** from the unpacked folder run `bash install_panel.sh`, and for a systemd service `sudo bash install_panel.sh --service`.
Nothing needs to be installed: Java and libraries come from the server itself. Details — [docs/EN](https://github.com/Torivald/PZPanel/blob/main/docs/EN/README.md).

**Upgrading from 1.3:** replace `pzpanel.jar` (and `pz-metrics.sh` if you use the remote mode) — `panel.properties` and data are untouched. From 1.4 on you can do this with the "Check for updates" button in the panel itself.

## What's new in 1.4

- **Version and "What's new".** The sidebar shows the panel version and a "What's new" button: a window with the list of changes in the interface language (after an update it opens once by itself).
- **Update check.** The "Check for updates" button looks at the latest GitHub release and, if a newer version is out, shows its notes and offers to **install** it: the archive for your system is downloaded, `pzpanel.jar` is replaced (the old one is kept as `pzpanel.jar.bak`), and you only need to restart the panel. On Windows the new file is applied on the next start of `PZPanel.bat`.

  ![Update check](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/update_en.png)
- **`pz-metrics.sh` for a panel in a separate container.** Inside a container it shows the consumption of the **whole container** (CPU, RAM as in `docker stats`, processes and threads from the cgroup); the server process is found through `/proc` (`ProjectZomboid64` or `java … zombie.network.GameServer`, no `pgrep`/`ps` needed), diagnostics go to stderr, a custom pattern via `PZ_MATCH`.
- Small fixes in the English interface translation.

## Full list of changes 1.3 → 1.4

**Added:** panel version, "What's new", update check and install, container mode in `pz-metrics.sh`.
**Changed:** version 1.4; `PZPanel.bat` puts `pzpanel.jar.new` in place if present; documentation.
