# 🇷🇺 Русский

Веб-панель выделенного сервера Project Zomboid (Build 42) — моды, миры, карта, игроки, бэкапы в одном окне браузера.

![Логи панели](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/panel_log.png)

## Скачать

| Система | Архив |
|---|---|
| **Windows** | `PZPanel_1.5_Windows.zip` (ниже, в «Assets») |
| **Linux** | `PZPanel_1.5_Linux.zip` (ниже, в «Assets») |

**Windows:** распакуйте папку `PZPanel` внутрь «Project Zomboid Dedicated Server», запустите `PZPanel.bat` → откроется http://127.0.0.1:8766/.
**Linux:** из распакованной папки выполните `bash install_panel.sh`, а для службы systemd — `sudo bash install_panel.sh --service`.
Подробности — [docs/RU](https://github.com/Torivald/PZPanel/blob/main/docs/RU/README.md).

**Обновление с 1.4:** замените `pzpanel.jar` (на Windows ещё и `PZPanel.bat`) — `panel.properties` и данные не затрагиваются. Это можно сделать кнопкой «Проверить обновление» в панели.

## Что нового в 1.5

- **Логи панели.** В окне консоли переключатель «Сервер / Панель»: журнал самой панели (запуск, ошибки, обновления) виден прямо в браузере и пишется в `pzpanel.log`.
- **Кнопка «Перезапустить панель».** Работает под systemd, в `PZPanel.bat` и в контейнере с `panelRestart=on`; если панель некому поднять, кнопка об этом сообщит и ничего не сделает.
- После установки обновления панель можно перезапустить сразу.

Предыдущие версии: [1.4](https://github.com/Torivald/PZPanel/releases/tag/v1.4) · [1.3](https://github.com/Torivald/PZPanel/releases/tag/v1.3) · [1.2](https://github.com/Torivald/PZPanel/releases/tag/v1.2)

# 🇬🇧 English

A web panel for a Project Zomboid (Build 42) dedicated server — mods, worlds, map, players, backups in one browser window.

![Panel logs](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/panel_log_en.png)

## Download

| System | Archive |
|---|---|
| **Windows** | `PZPanel_1.5_Windows.zip` (in "Assets" below) |
| **Linux** | `PZPanel_1.5_Linux.zip` (in "Assets" below) |

**Windows:** unpack the `PZPanel` folder into "Project Zomboid Dedicated Server" and run `PZPanel.bat` → http://127.0.0.1:8766/ opens.
**Linux:** from the unpacked folder run `bash install_panel.sh`, and for a systemd service `sudo bash install_panel.sh --service`.
Details — [docs/EN](https://github.com/Torivald/PZPanel/blob/main/docs/EN/README.md).

**Upgrading from 1.4:** replace `pzpanel.jar` (and `PZPanel.bat` on Windows) — `panel.properties` and data are untouched. You can do it with the "Check for updates" button in the panel.

## What's new in 1.5

- **Panel logs.** A "Server / Panel" switch in the console window: the panel's own log (start-up, errors, updates) is visible in the browser and written to `pzpanel.log`.
- **"Restart panel" button.** Works under systemd, in `PZPanel.bat`, and in a container with `panelRestart=on`; if nothing would start the panel again, the button says so and does nothing.
- After installing an update the panel can be restarted right away.

Previous versions: [1.4](https://github.com/Torivald/PZPanel/releases/tag/v1.4) · [1.3](https://github.com/Torivald/PZPanel/releases/tag/v1.3) · [1.2](https://github.com/Torivald/PZPanel/releases/tag/v1.2)
