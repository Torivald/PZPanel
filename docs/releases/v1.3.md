## Что нового в 1.3

### 🔀 Автосортировка модов
Кнопка **«Сортировать…»** на вкладке «Моды» (идея — мод [Mod Load Order Sorter [b42]](https://steamcommunity.com/sharedfiles/filedetails/?id=3423660713), но прямо в панели):
- **Исправить порядок** — ваш порядок сохраняется, сдвигаются только моды, нарушающие `require` / `loadModAfter` / `loadModBefore`;
- **По категориям и алфавиту** — библиотеки → ресурсы → карты → транспорт → код → одежда → интерфейс → прочее → переводы, затем та же проверка зависимостей;
- предпросмотр с самыми большими перемещениями, предупреждения о циклических зависимостях, отсутствующих требованиях и несовместимых модах; в сервер попадает только после «Применить» и «Сохранить».

### ⬇ Скачивание замороженных модов игроками
![Скачать с сервера](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/download.png)
У замороженного мода появилась кнопка **«⬇ Скачать с сервера»** с выбором: **только этот мод** или **запаковать все установленные моды** (в архиве — папки модов, `default.txt` с порядком, как на сервере, манифест и README). Архив собирается в фоне, затем даётся ссылка для скачивания.
**Политика хранения:** полный архив всегда один (новый заменяет прежний), архив одного мода удаляется через 24 часа (`modArchiveTtlHours`), недособранные файлы чистятся автоматически; карточка «Архивы модов для игроков» показывает список и позволяет удалить архив вручную.

![Архивы модов](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/mods_archives.png)

# 🇬🇧 English

A web panel for a Project Zomboid (Build 42) dedicated server — mods, worlds, map, players, backups in one browser window.

## Download

| System | Archive |
|---|---|
| **Windows** | `PZPanel_1.3_Windows.zip` (in "Assets" below) |
| **Linux** | `PZPanel_1.3_Linux.zip` (in "Assets" below) |

**Windows:** unpack the `PZPanel` folder into "Project Zomboid Dedicated Server" and run `PZPanel.bat` → http://127.0.0.1:8766/ opens.
**Linux:** from the unpacked folder run `bash install_panel.sh`, and for a systemd service `sudo bash install_panel.sh --service`.
Nothing needs to be installed: Java and libraries come from the server itself. Details — [docs/EN](https://github.com/Torivald/PZPanel/blob/main/docs/EN/README.md).

**Upgrading from 1.2:** replace `pzpanel.jar` (and `pzpanel.sh`/`PZPanel.bat` if you did not change them) — `panel.properties` and data are untouched.

## What's new in 1.3

### 🔀 Mod auto-sorter
The **"Sort…"** button on the "Mods" tab (the idea comes from the [Mod Load Order Sorter [b42]](https://steamcommunity.com/sharedfiles/filedetails/?id=3423660713) mod, but right in the panel):
- **Fix the order** — your order is kept, only mods that break `require` / `loadModAfter` / `loadModBefore` are moved;
- **By category and alphabet** — libraries → resources → maps → vehicles → code → clothing → interface → other → translations, then the same dependency check;
- a preview with the biggest moves, warnings about circular dependencies, missing requirements and incompatible mods; nothing reaches the server until "Apply" and "Save".

### ⬇ Downloading frozen mods by players
![Download from server](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/download.png)
A frozen mod gets a **"⬇ Download from server"** button with a choice: **only this mod** or **pack all installed mods** (the archive has the mod folders, a `default.txt` with the server's order, a manifest and a README). The archive is built in the background, then a download link is given.
**Retention policy:** there is always one full archive (a new one replaces the old), a single-mod archive is deleted after 24 hours (`modArchiveTtlHours`), unfinished files are cleaned automatically; the "Mod archives for players" card lists archives and lets you delete one by hand.

![Mod archives](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/mods_archives.png)

### 🌐 Interface language: Russian and English
![English](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/lang_en.png)
A switch in the sidebar; the choice is kept in each user's browser (by default — the browser language). The interface, messages and confirmations are translated. Descriptions of `.ini` options come from the server file and stay as they are.

### 📚 Documentation
Split into files in `docs/RU` and `docs/EN` (overview, installation, configuration, mods, map, Docker, architecture, troubleshooting); the main README and the changelog are bilingual.

### Compatibility
The new features only add code; server start/stop logic and `serverMode=remote` (with `startRequestFile`) work as before.

**Changed:** version 1.3; documentation structure.
