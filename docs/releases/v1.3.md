Веб-панель выделенного сервера Project Zomboid (Build 42) — моды, миры, карта, игроки, бэкапы в одном окне браузера.

![Автосортировка модов](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/sorter.png)

## Скачать

| Система | Архив |
|---|---|
| **Windows** | `PZPanel_1.3_Windows.zip` (ниже, в «Assets») |
| **Linux** | `PZPanel_1.3_Linux.zip` (ниже, в «Assets») |

**Windows:** распакуйте папку `PZPanel` внутрь «Project Zomboid Dedicated Server», запустите `PZPanel.bat` → откроется http://127.0.0.1:8766/.
**Linux:** из распакованной папки выполните `bash install_panel.sh`, а для службы systemd — `sudo bash install_panel.sh --service`.
Панели не нужно ничего ставить: Java и библиотеки берутся из самого сервера. Подробности — [docs/PANEL.md](https://github.com/Torivald/PZPanel/blob/main/docs/PANEL.md).

**Обновление с 1.2:** замените `pzpanel.jar` (и `pzpanel.sh`/`PZPanel.bat`, если не меняли их) — `panel.properties` и данные не затрагиваются. Запуск сервера, `serverMode=remote` и `startRequestFile` работают как в 1.2.

## Что нового в 1.3

### 🔀 Автосортировка модов
Кнопка **«Сортировать…»** на вкладке «Моды» (идея — мод [Mod Load Order Sorter [b42]](https://steamcommunity.com/sharedfiles/filedetails/?id=3423660713), но прямо в панели):
- **Исправить порядок** — ваш порядок сохраняется, сдвигаются только моды, нарушающие `require` / `loadModAfter` / `loadModBefore`;
- **По категориям и алфавиту** — библиотеки → ресурсы → карты → транспорт → код → одежда → интерфейс → прочее → переводы, затем та же проверка зависимостей;
- предпросмотр с самыми большими перемещениями, предупреждения о циклических зависимостях, отсутствующих требованиях и несовместимых модах; в сервер попадает только после «Применить» и «Сохранить».

### ⬇ Скачивание замороженных модов игроками
![Скачать с сервера](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/download.png)
У замороженного мода появилась кнопка **«⬇ Скачать с сервера»** с выбором: **только этот мод** или **запаковать все установленные моды** (в архиве — папки модов, `default.txt` с порядком, как на сервере, манифест и README). Архив собирается в фоне, затем даётся ссылка для скачивания.
**Политика хранения:** полный архив всегда один (новый заменяет прежний), архив одного мода удаляется через 24 часа (`modArchiveTtlHours`), недособранные файлы чистятся автоматически; карточка «Архивы модов для игроков» показывает список и позволяет удалить архив вручную.

![Архивы модов](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/mods_archives.png)

### 🌐 Язык интерфейса: русский и English
![English](https://raw.githubusercontent.com/Torivald/PZPanel/main/docs/screenshots/lang_en.png)
Переключатель в боковой панели; выбор хранится в браузере каждого пользователя (по умолчанию — язык браузера). Переведены интерфейс, сообщения и подтверждения. Описания параметров `.ini` берутся из файла сервера и остаются как есть.

### Совместимость
Новые функции только добавляют код; логика запуска/остановки сервера и режим `serverMode=remote` (с `startRequestFile`) не менялись — проверено на локальном и remote-режиме.

## Полный список изменений 1.2 → 1.3

**Добавлено:** автосортировка модов, скачивание замороженных модов (один мод / все), политика хранения архивов, `modArchiveTtlHours`, переключатель языка (русский/English), скриншоты новых функций.
