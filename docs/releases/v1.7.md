# 🇷🇺 Русский

Веб-панель выделенного сервера Project Zomboid (Build 42) — моды, миры, карта, игроки, бэкапы в одном окне браузера.

## Скачать

| Система | Архив |
|---|---|
| **Windows** | `PZPanel_1.7_Windows.zip` (ниже, в «Assets») |
| **Linux** | `PZPanel_1.7_Linux.zip` (ниже, в «Assets») |

**Windows:** распакуйте папку `PZPanel` внутрь «Project Zomboid Dedicated Server», запустите `PZPanel.bat` → откроется http://127.0.0.1:8766/.
**Linux:** из распакованной папки выполните `bash install_panel.sh`, а для службы systemd — `sudo bash install_panel.sh --service`.
Подробности — [docs/RU](https://github.com/Torivald/PZPanel/blob/main/docs/RU/README.md).

**Обновление с 1.5 / 1.6.x:** замените `pzpanel.jar` (на Windows ещё и `PZPanel.bat`) — `panel.properties` и данные не затрагиваются. Это можно сделать кнопкой «Проверить обновление» в панели.

## Что нового в 1.7

- **Обновление сервера Project Zomboid из панели.** Новая вкладка «Версия игры»: установленная версия, ветки Steam (public, pre-release, откатные) с датами сборок и кнопка «Обновить» — SteamCMD скачивает новую версию, сервер должен быть остановлен.
- **Настройки запуска не теряются.** Перед обновлением панель сохраняет `StartServer64.bat` и `ProjectZomboid64.json`, а после возвращает в новые файлы ZombieBuddy, память Java, сборщик мусора и `-servername`. Для обновлений через Steam-клиент — кнопки «Запомнить» и «Вернуть настройки запуска».
- **Docker:** если папка сервера смонтирована в контейнер панели, панель обновляет сервер сама; иначе — файл-запрос `updateRequestFile` для обработчика на хосте (пример в документации).

Подробнее — [docs/RU/README.md](https://github.com/Torivald/PZPanel/blob/main/docs/RU/README.md#версия-игры-и-обновление-сервера).

## Что нового в 1.6.2

- **Обновление ZombieBuddy через панель.** Вкладка ZombieBuddy показывает версии агента сервера и копий мода и дату обновления в Мастерской. «Скачать последнюю версию» берёт её через SteamCMD (без аккаунта Steam), «Установить выбранную версию» ставит `ZombieBuddy.jar` туда, откуда его грузит сервер (на Windows вместе с `zbNative.dll`), и обновляет замороженный мод. Прежние версии сохраняются.
- **«Обновить authors.json».** Свежий список доверенных авторов Java-модов с GitHub ZombieBuddy — в `~/.zombie_buddy/authors.json`.

Подробнее — [docs/RU/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/RU/MODS.md#обновление-zombiebuddy).

## Что нового в 1.6.1

- **Моды на диске.** Новая карточка на вкладке «Моды»: все моды сервера с размерами (`Zomboid/mods` и скачанные сервером предметы Мастерской). Можно удалить выбранные или все — например, чтобы освободить место или поставить мод заново; по желанию их моды сразу убираются из списка модов мира.
- **Прежние версии.** Папки, заменённые загрузкой архивом (`Zomboid/mods_replaced`), видны в панели: «Вернуть» или «Удалить». Старше 30 дней удаляются сами (`modReplacedKeepDays`).

Подробнее — [docs/RU/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/RU/MODS.md#моды-на-диске-и-прежние-версии).

## Что нового в 1.6

- **Загрузка мода архивом.** На вкладке «Моды» — карточка «Загрузить мод архивом»: мод не из Мастерской, своя сборка, предмет, скачанный вручную, или архив модов для игроков. Панель находит папки модов по `mod.info`, показывает, что нашла (id, Java-код, совпадения с установленными модами), ставит их в `Zomboid/mods` и включает выбранные моды. Сервер такие моды из Steam не обновляет.
- Прежняя папка с тем же именем не удаляется, а переносится в `Zomboid/mods_replaced/<дата_время>/`.
- Можно указать ID предмета Мастерской — мод попадёт в список закреплённых, а Java-код можно сразу разрешить в ZombieBuddy.
- Новый параметр `modUploadMaxMb` — предельный размер архива (4096 МБ).
- **Windows:** `PZPanel.bat` и другие `.bat` теперь только латиницей — больше не ломаются из-за кодировки (`'exist' is not recognized…`).

Подробнее — [docs/RU/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/RU/MODS.md#загрузить-мод-архивом).

# 🇬🇧 English

A web panel for a Project Zomboid (Build 42) dedicated server — mods, worlds, map, players, backups in one browser window.

## Download

| System | Archive |
|---|---|
| **Windows** | `PZPanel_1.7_Windows.zip` (in "Assets" below) |
| **Linux** | `PZPanel_1.7_Linux.zip` (in "Assets" below) |

**Windows:** unpack the `PZPanel` folder into "Project Zomboid Dedicated Server" and run `PZPanel.bat` → http://127.0.0.1:8766/ opens.
**Linux:** from the unpacked folder run `bash install_panel.sh`, and for a systemd service `sudo bash install_panel.sh --service`.
Details — [docs/EN](https://github.com/Torivald/PZPanel/blob/main/docs/EN/README.md).

**Upgrading from 1.5 / 1.6.x:** replace `pzpanel.jar` (and `PZPanel.bat` on Windows) — `panel.properties` and data are untouched. You can do it with the "Check for updates" button in the panel.

## What's new in 1.7

- **Update the Project Zomboid server from the panel.** A new "Game version" tab: the installed version, Steam branches (public, pre-release, fall-back ones) with build dates and an "Update" button — SteamCMD downloads the new version; the server must be stopped.
- **Launch settings are kept.** Before updating, the panel saves `StartServer64.bat` and `ProjectZomboid64.json`, and afterwards puts ZombieBuddy, Java memory, the garbage collector and `-servername` back into the new files. For updates via the Steam client there are "Remember" and "Restore launch settings" buttons.
- **Docker:** if the server folder is mounted into the panel container, the panel updates the server itself; otherwise an `updateRequestFile` request for a host handler (example in the docs).

Details — [docs/EN/README.md](https://github.com/Torivald/PZPanel/blob/main/docs/EN/README.md#game-version-and-server-update).

## What's new in 1.6.2

- **Update ZombieBuddy from the panel.** The ZombieBuddy tab shows the versions of the server agent and mod copies and the Workshop update date. "Download the latest version" gets it via SteamCMD (no Steam account), "Install the selected version" puts `ZombieBuddy.jar` where the server loads it from (with `zbNative.dll` on Windows) and updates the frozen mod. Old versions are kept.
- **"Update authors.json".** The fresh list of trusted Java mod authors from ZombieBuddy's GitHub — into `~/.zombie_buddy/authors.json`.

Details — [docs/EN/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/EN/MODS.md#updating-zombiebuddy).

## What's new in 1.6.1

- **Mods on disk.** A new card on the "Mods" tab: all the server's mods with sizes (`Zomboid/mods` and Workshop items downloaded by the server). Delete selected ones or all of them — e.g. to free space or reinstall a mod; optionally their mods are removed from the world's mod list right away.
- **Old versions.** Folders replaced by archive uploads (`Zomboid/mods_replaced`) are shown in the panel: "Restore" or "Delete". Older than 30 days are deleted automatically (`modReplacedKeepDays`).

Details — [docs/EN/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/EN/MODS.md#mods-on-disk-and-old-versions).

## What's new in 1.6

- **Upload a mod as an archive.** The "Mods" tab has an "Upload a mod as an archive" card: a non-Workshop mod, your own build, an item downloaded by hand, or a players' mod archive. The panel finds the mod folders by `mod.info`, shows what it found (ids, Java code, clashes with installed mods), puts them into `Zomboid/mods` and enables the chosen mods. The server does not update such mods from Steam.
- An older folder with the same name is not deleted but moved to `Zomboid/mods_replaced/<date_time>/`.
- You can give the Workshop item ID — the mod joins the pinned list, and its Java code can be approved in ZombieBuddy right away.
- New option `modUploadMaxMb` — the archive size limit (4096 MB).
- **Windows:** `PZPanel.bat` and the other `.bat` files are now ASCII-only and no longer break because of the encoding (`'exist' is not recognized…`).

Details — [docs/EN/MODS.md](https://github.com/Torivald/PZPanel/blob/main/docs/EN/MODS.md#upload-a-mod-as-an-archive).
