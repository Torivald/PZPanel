# PZ Panel — веб-панель управления сервером Project Zomboid

Панель — небольшая программа на Java (файл `pzpanel.jar`, ~80 КБ), которая работает рядом с выделенным сервером и открывается в браузере.
Ничего ставить не нужно: Java берётся из самого сервера (`jre64`), а библиотеки SQLite и JSON — из `projectzomboid.jar`.

В архиве сервера: папка `panel/` — `pzpanel.jar`, `pzpanel.sh` (запуск), `pzpanel.service` (systemd); скрипт `scripts/05_install_panel.sh`.
На Windows-ПК хоста панель лежит в папке сервера, `PZPanel\` (запуск — `PZPanel.bat`).
Исходники — `panel/src/` (сборка: `build.sh` / `build.bat`). Эта же инструкция в Steam: [руководство PZ Panel](https://steamcommunity.com/sharedfiles/filedetails/?id=3820094636).

## Что умеет

| Вкладка | Что там |
|---|---|
| **Обзор и консоль** | Состояние сервера, аптайм, онлайн. **Нагрузка**: ЦПУ и ОЗУ процесса сервера (вместе с дочерними процессами) с графиками за 30 минут, лимит Java (-Xmx) и пик памяти, загрузка всей машины. Кнопки: запустить, перезапустить (с предупреждением игроков за 1/5/10 минут), остановить (save + quit), сохранить мир, убить процесс. Живая консоль и ввод команд (`players`, `servermsg "текст"`, `additem` …). Вопросы ZombieBuddy `[y/n]` — кнопками «Да/Нет» |
| **Карта** | Интерактивная карта мира — подробно в разделе «Карта» ниже |
| **Игроки** | Аккаунты, роли, последний вход, персонажи и их координаты; кик, бан, смена роли |
| **Моды** | Порядок загрузки (перетаскиванием), включение/выключение, проверка `require` / `loadModAfter` / `versionMax`. Поиск в Мастерской, добавление по ссылке/ID, импорт коллекции. Метка **«локальный»** — мод лежит в `Zomboid/mods` (заморожен) |
| **Настройки сервера** | `<имя>.ini` формой, с поиском |
| **Песочница** | `<имя>_SandboxVars.lua` формой, по группам (опции модов тоже) |
| **Файлы** | Любой конфиг текстом: ini, песочница, точки появления, моды клиента, скрипт запуска |
| **ZombieBuddy** | Одобрения Java-модов (`mod_approvals.json`) |
| **Бэкапы** | Zip-копии мира: создать, скачать, удалить |
| **Панель** | Настройки самой панели (`panel.properties`) |

Перед каждым сохранением файла из панели прежняя версия кладётся в `PZPanel/file_backups/`.
Изменения ini и песочницы применяются после перезапуска сервера — панель покажет плашку «нужен перезапуск».

## Карта

Всё берётся прямо из файлов карты игры на сервере (`media/maps/Muldraugh, KY`): панель читает их при запуске за несколько секунд, ничего рендерить не нужно. Подложка «вид сверху» — по желанию, см. ниже.

- **Поиск** (поле сверху): игроки по нику, города, улицы, точки интереса по типу — «аптека», «оружейный», «полиция», «заправка», «gunstore»… Точки интереса сортируются по расстоянию от центра экрана. Клик по результату — перелёт к месту.
- **Игроки**: онлайн (зелёные), оффлайн (синие), мёртвые (красные), список с переходом. Позиции обновляются, когда сервер сохраняет мир (кнопка «Обновить позиции» делает `save`).
- **Точки интереса** — здания, классифицированные по комнатам: медицина и аптеки, полиция, оружие и охота, военные, тюрьма, заправки, продукты, пожарные, автосервис, инструменты и склады, одежда и спорт, электроника, книги, кафе и бары, спортзалы, школы, церкви, мотели, банки и почта, фермы, другие магазины, гаражи и сараи (выключены по умолчанию — их тысячи). Галочки включают и выключают категории.
- **Здания**: при приближении видны контуры домов; цвет — категория. Клик по зданию или точке — карточка: комнаты **по этажам** (и подвал), координаты, «Копировать координаты» и **«Телепортировать сюда»** (выбранного онлайн-игрока, команда `teleportto`).
- **Слои**: города, улицы с названиями, плотность зомби (как задано картой игры, без учёта настроек песочницы), точки появления (с профессиями), сюжетные места, подвалы, богатые районы, трейлерные парки, фермы и ранчо.
- **Ссылка на место** — кнопка 🔗 копирует адрес вида `http://127.0.0.1:8766/#map@12800,1780,1.2` (x, y, масштаб). Открыв его, панель покажет это место.
- Под картой — координаты курсора и ближайший город.

### Подложка «вид сверху» (необязательно)

Обычная подложка — карта из самой игры. «Вид сверху» — настоящие тайлы мира (крыши, дороги, деревья) и **отдельно каждый этаж**. Рисуется один раз программой [pzmap2dzi](https://github.com/cff29546/pzmap2dzi) (MIT) на **Windows-ПК с установленной игрой** — текстуры есть только в клиенте игры, не в выделенном сервере.

1. На Windows-ПК с игрой запустите **`render_top_view.bat`** (лежит в `PZPanel` в папке сервера на ПК хоста; в архиве Linux-сервера — `panel/render_top_view.bat` и `.ps1`, их можно положить в любую папку). Скрипт сам скачает pzmap2dzi (зафиксированная версия), поставит Python-зависимости (если Python нет — предложит поставить через winget), найдёт игру и запустит рендер.
   - Размер: `render_top_view.bat 1` — ~1 ч, ~100 МБ; **`2` (по умолчанию)** — 1–2 ч, ~300 МБ; `4` — 2–4 ч, ~1 ГБ. Время зависит от процессора.
   - Прервать можно в любой момент — повторный запуск продолжит с места остановки.
   - Игра в другой папке: `render_top_view.bat 2 "D:\SteamLibrary\steamapps\common\ProjectZomboid"`. Если скрипт лежит не в папке сервера рядом с игрой — путь к игре указывать обязательно; результат появится в папке `map` рядом со скриптом.
2. Результат — `map\html\map_data\base_top` рядом со скриптом. Перезапустите панель: в «Подложка» появится «Вид сверху» и выбор этажа. Папку `map\texture` (~500 МБ) после рендера можно удалить.
3. Для **Linux-сервера** скопируйте результат к панели на сервере:
   ```bash
   scp -r "PZPanel/map/html/map_data/base_top" pzuser@IP_СЕРВЕРА:~/pzserver/PZPanel/map/html/map_data/
   ```
   (создайте папку `~/pzserver/PZPanel/map/html/map_data` заранее), затем `sudo systemctl restart pzpanel`. Другой путь можно указать в `topViewDir`.

## Windows (сервер на этом ПК)

1. Папка `PZPanel` должна лежать **внутри** папки сервера: `...\steamapps\common\Project Zomboid Dedicated Server\PZPanel\`.
2. Двойной клик по **`PZPanel.bat`**. Откроется браузер: http://127.0.0.1:8766/
3. Окно консоли панели не закрывайте, пока пользуетесь панелью. Сервер, запущенный из панели, пишет консоль прямо в неё. Если закрыть панель, сервер продолжит работать (но ответить ZombieBuddy уже будет негде — тогда запускайте сервер через `StartServer64.bat`).

Если сервер запущен не из панели (через `StartServer64.bat`), панель его увидит. Команды пойдут через RCON (нужен `RCONPassword` в ini), консоль будет недоступна.

## Linux

### Установка

От пользователя `pzuser`, из распакованного архива:

```bash
bash scripts/05_install_panel.sh
```

Скрипт кладёт панель в `~/pzserver/PZPanel/` и создаёт `panel.properties` для Linux.

### Вариант А — панель как служба (рекомендуется)

Панель запускается при загрузке машины, сама стартует сервер, а при остановке службы или перезагрузке сохраняет мир и корректно выключает сервер.

```bash
sudo bash scripts/05_install_panel.sh --service
```

Скрипт отключит старую службу `pzserver` (tmux), если она была включена: двумя способами одновременно сервер запускать нельзя.

```bash
systemctl status pzpanel          # состояние
journalctl -u pzpanel -f          # лог панели и сервера
sudo systemctl restart pzpanel    # перезапуск панели (и сервера: save + quit, затем снова старт)
```

Консоль сервера и вопросы ZombieBuddy — на вкладке «Обзор и консоль».

### Вариант Б — сервер в tmux, панель рядом

Сервер как раньше (`scripts/start.sh` или служба `pzserver`), панель запускается вручную: `~/pzserver/PZPanel/pzpanel.sh`.
Панель увидит сервер и будет работать через RCON. В `panel.properties` поставьте `autoStartServer=false` и `stopServerOnExit=false`.
Консоль сервера в этом варианте — только в tmux (`tmux attach -t pz`).

### Как открыть панель с вашего ПК

Панель слушает только `127.0.0.1` на сервере — снаружи её не видно. Откройте SSH-туннель с вашего ПК:

```bash
ssh -L 8766:127.0.0.1:8766 pzuser@IP_СЕРВЕРА
```

и, пока соединение открыто, заходите в браузере на **http://127.0.0.1:8766/**.
На Windows это работает в PowerShell (OpenSSH встроен) или в PuTTY: Connection → SSH → Tunnels, Source port `8766`, Destination `127.0.0.1:8766`.

Открывать панель в интернет напрямую (`bind=0.0.0.0`) не рекомендуется: в ней нет HTTPS. Если очень нужно — задайте `panelPassword`, откройте порт только для своего IP и перезапустите панель.

## Настройки (`panel.properties`)

Файл рядом с `pzpanel.jar`. Его же можно править на вкладке «Панель». После смены `bind`/`port` перезапустите панель.

| Параметр | По умолчанию | Что это |
|---|---|---|
| `serverDir` | папка выше панели | Папка выделенного сервера |
| `startScript` | `StartServer64.bat` / `start-server.sh` | Скрипт запуска сервера |
| `zomboidDir` | `~/Zomboid` | Конфиги, миры, логи, `mods` |
| `serverName` | из `-servername` в скрипте запуска | Имя сервера: `<имя>.ini`, мир `Saves/Multiplayer/<имя>` |
| `bind`, `port` | `127.0.0.1`, `8766` | Где слушает панель |
| `panelPassword` | пусто | Пароль входа (обязателен, если `bind` не 127.0.0.1) |
| `openBrowser` | `true` | Открыть браузер при старте (только Windows) |
| `autoStartServer` | `false` (Linux-установка: `true`) | Запускать сервер вместе с панелью |
| `stopServerOnExit` | `false` (Linux-установка: `true`) | При закрытии панели — save + quit серверу |
| `stopTimeoutSec` | `170` | Сколько ждать выключения сервера |
| `autoRestartOnCrash` | `false` | Перезапускать упавший сервер (запущенный из панели) |
| `dailyRestart` | пусто | Ежедневный перезапуск в `ЧЧ:ММ` (время сервера) |
| `restartWarnMinutes` | `5` | За сколько минут предупреждать игроков |
| `serverMode` | `local` | `remote` — сервер работает в другом контейнере: «запущен» определяется по открытому RCON-порту, запуск и жёсткая остановка — средствами контейнера |
| `rconHost` | `127.0.0.1` | Адрес RCON сервера; при `serverMode=remote` — имя контейнера или хост сервера |
| `gameVersion` | `42.21` | Для проверки `versionMax` модов |
| `pyramidZip` | авто | Путь к `pyramid.zip` карты, если она не нашлась сама |
| `workshopDirs` | авто | Доп. папки Мастерской через `;` |
| `zbConfigDir` | `~/.zombie_buddy` | Где лежат одобрения ZombieBuddy |
| `mapDir` | `<serverDir>/media/maps/Muldraugh, KY` | Файлы карты для слоёв (здания, улицы, зоны) |
| `topViewDir` | `<панель>/map/html/map_data/base_top` | Результат рендера «вид сверху» |

## Панель в отдельном контейнере

Панель можно запускать отдельно от сервера, например двумя контейнерами Docker. В обоих монтируются одни и те же папки
(папка сервера, `Zomboid`, `~/.zombie_buddy`); в `panel.properties`:

```
serverMode=remote
rconHost=<имя контейнера или хост сервера>
```

Сервер панель находит по открытому RCON-порту, команды идут через RCON. Процесса сервера в её контейнере нет, поэтому для
PID, времени работы и графиков ЦПУ/ОЗУ внутри контейнера **сервера** запустите `pz-metrics.sh` из `dist/linux`:

```
ZOMBOID_DIR=/путь/к/Zomboid ./pz-metrics.sh &
```

Скрипт раз в 5 с пишет `<Zomboid>/.panel-metrics.json`; данные старше 20 с панель считает устаревшими и показывает «нет свежих метрик».
«Остановить» в этом режиме отправляет `save` и `quit` (если у контейнера есть restart policy, сервер поднимется заново),
«Запустить» и «Убить» недоступны.

## Панель и замороженные моды

После заморозки (`scripts/04_freeze_mods.sh` или `freeze_mods.bat`) моды на вкладке «Моды» помечены **«локальный»**, а список «Предметы Мастерской» пуст — так и должно быть.

Если добавить через панель **новый** мод из Мастерской, его предмет попадёт в `WorkshopItems=`, и сервер будет качать из Steam только его. Чтобы заморозить и его:
остановите сервер → запустите один раз (мод скачается) → остановите → `bash scripts/04_freeze_mods.sh` (на Windows — `freeze_mods.bat`) → разошлите игрокам новый архив модов (он появится в `~`, на Windows — в папке сервера). Уже замороженные моды при этом не перекопируются и не обновятся — добавится только новый, а архив соберётся со всеми модами. Если сервер не заморожен и моды просто обновились — `bash scripts/03_build_mods_archive.sh` соберёт свежий архив, ничего не меняя.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Браузер пишет «Forbidden host» | Заходите именно на `127.0.0.1` или `localhost` (через туннель) |
| «Не найдена Java» / «Не найден projectzomboid.jar» | Панель должна лежать в `~/pzserver/PZPanel` (Windows: в папке сервера), сервер установлен |
| Карта серая | Нет `pyramid.zip`: укажите путь в `pyramidZip` (лежит в `media/maps/Muldraugh, KY/` сервера или игры) |
| «Слои карты недоступны» | Не найдена папка карты — укажите `mapDir` (папка `media/maps/Muldraugh, KY` сервера) |
| «Вид сверху» недоступен | Не рендерили или не скопировали `base_top` — раздел «Подложка „вид сверху“» |
| Кнопки команд не работают, сервер запущен не из панели | Задайте `RCONPassword` в ini и перезапустите сервер |
| Порт 8766 занят | Смените `port` в `panel.properties` (и в SSH-туннеле) |
