# PZ Panel — подробное описание

PZ Panel — веб-панель выделенного сервера Project Zomboid (Build 42). Небольшая программа на Java (`pzpanel.jar`, около 200 КБ), которая работает рядом с сервером и открывается в браузере: с ПК, телефона или через интернет. Ничего ставить не нужно: Java берётся из самого сервера (`jre64`), библиотеки SQLite и JSON — из `projectzomboid.jar`. Работает на Windows и Linux (на Linux — как служба systemd или в отдельном контейнере Docker).

## Вкладки панели

![Обзор и консоль](../screenshots/overview.png)

![Миры](../screenshots/worlds.png)

| Вкладка | Что там |
|---|---|
| **Обзор и консоль** | Состояние сервера, аптайм, онлайн. **Нагрузка**: ЦПУ и ОЗУ процесса сервера (вместе с дочерними процессами) с графиками за 30 минут, лимит Java (-Xmx) и пик памяти, загрузка всей машины. Кнопки: запустить, перезапустить (с предупреждением игроков за 1/5/10 минут), остановить (save + quit), сохранить мир, убить процесс. Живая консоль и ввод команд (`players`, `servermsg "текст"`, `additem` …). Вопросы ZombieBuddy `[y/n]` — кнопками «Да/Нет» |
| **Карта** | Интерактивная карта мира — подробно в разделе «Карта» ниже |
| **Игроки** | Аккаунты, роли, последний вход, персонажи и их координаты; кик, бан, смена роли |
| **Моды** | Порядок загрузки (перетаскиванием), включение/выключение, проверка `require` / `loadModAfter` / `versionMax`. Поиск в Мастерской, добавление по ссылке/ID, импорт коллекции. Метка **«локальный»** — мод лежит в `Zomboid/mods` (заморожен) |
| **Настройки сервера** | `<имя>.ini` формой, с поиском |
| **Песочница** | `<имя>_SandboxVars.lua` формой, по группам (опции модов тоже) |
| **Файлы** | Любой конфиг текстом: ini, песочница, точки появления, моды клиента, скрипт запуска |
| **ZombieBuddy** | Одобрения Java-модов (`mod_approvals.json`) |
| **Бэкапы** | Zip-копии мира: создать, скачать, удалить |
| **Панель** | Настройки самой панели (`panel.properties`) |

Перед каждым сохранением файла из панели прежняя версия кладётся в `PZPanel/file_backups/`.
Изменения ini и песочницы применяются после перезапуска сервера — панель покажет плашку «нужен перезапуск».

## Главное

- **Моды** — порядок загрузки перетаскиванием, поиск в Мастерской, замораживание версии («📌 Закрепить»), [автосортировка](MODS.md#автосортировка-модов), [скачивание замороженных модов игроками](MODS.md#скачивание-модов-игроками).
- **Миры** — несколько миров (имён сервера) со своими настройками, модами и песочницей; сброс, копия, перенос, бэкап перед опасными действиями.
- **Карта** — игроки, здания по категориям, улицы, плотность зомби, поиск, телепорт, подложка «вид сверху» — см. [Карта](MAP.md).
- **Нагрузка** — ЦПУ и ОЗУ сервера с графиками за 30 минут.
- **Язык интерфейса** — русский и English, выбор запоминается у каждого пользователя ([подробнее](CONFIG.md#язык-интерфейса)).
- **Безопасность** — вход по паролю (`panelPassword`), токен против CSRF, защита от подмены Host; по умолчанию панель слушает только `127.0.0.1`.

## Версия и обновления

![Что нового](../screenshots/whatsnew.png)

В боковом меню под списком вкладок показана версия панели и две кнопки:

- **«Что нового»** — окно со списком изменений текущей версии (и предыдущих) на выбранном языке интерфейса. После обновления окно показывается один раз само.
- **«Проверить обновление»** — панель запрашивает последний релиз в репозитории на GitHub (нужен доступ с сервера к `api.github.com`) и сравнивает версию со своей. Если вышла новая, показывает её описание и предлагает **«Установить обновление»**: скачивается архив релиза для вашей системы, из него берётся `pzpanel.jar`, прежний сохраняется как `pzpanel.jar.bak`, затем остаётся перезапустить панель. Скрипты запуска и `panel.properties` не меняются. На Windows запущенный jar заменить нельзя — новый файл ждёт как `pzpanel.jar.new` и подставляется при следующем запуске `PZPanel.bat`.
