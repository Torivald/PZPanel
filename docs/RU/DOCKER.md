# Панель в отдельном контейнере

Панель можно запускать отдельно от сервера, например двумя контейнерами Docker. В обоих монтируются одни и те же папки
(папка сервера, `Zomboid`, `~/.zombie_buddy`); в `panel.properties`:

```
serverMode=remote
rconHost=<имя контейнера или хост сервера>
```

Сервер панель находит по открытому RCON-порту, команды идут через RCON. Процесса сервера в её контейнере нет, поэтому для
PID, времени работы и графиков ЦПУ/ОЗУ внутри контейнера **сервера** запустите `pz-metrics.sh` из `dist/linux`:

```
ZOMBOID_DIR=/путь/к/Zomboid ./pz-metrics.sh &
```

Скрипт раз в 5 с пишет `<Zomboid>/.panel-metrics.json`; данные старше 20 с панель считает устаревшими и показывает «нет свежих метрик».
«Остановить» в этом режиме отправляет `save` и `quit` (если у контейнера есть restart policy, сервер поднимется заново),
«Запустить» и «Убить» недоступны.
